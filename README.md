## 📖 What is this?

Every so often, an AI system doesn't just automate a task — it **discovers something new about the world**, beats a record that stood for half a century, or restores an ability someone thought they'd lost forever.

This repository collects those moments, organized by field. Each entry is a short, honest write-up: what happened, when, why it matters, and — most importantly — **links to the primary sources** (papers, official announcements, reputable reporting) so you can verify it yourself.

The bar for inclusion is high:

- ✅ **Documented** — backed by a peer-reviewed paper, official research release, or credible reporting.
- ✅ **Concrete** — a specific result, not a vague "AI is transforming X" claim.
- ✅ **Notable** — a record broken, an open problem cracked, a first-of-its-kind, or a real-world deployment.

## ⭐ Five to start with

New here? These are among the most consequential entries in the collection:

1. **[AlphaFold](./chemistry/)** — solved a 50-year grand challenge in biology and won the 2024 Nobel Prize in Chemistry. Structures for ~200M proteins, free to the world.
2. **[Fusion plasma control](./physics/)** — reinforcement learning drove a *real* nuclear-fusion reactor's magnetic coils.
3. **[FunSearch](./mathematics/)** — the first time a large language model produced a verifiable, genuinely new answer to a long-open math problem.
4. **[AlphaDev sorting](./computer-science/)** — an AI-discovered algorithm merged into the C++ standard library, the first change there in over a decade.
5. **[Speech neuroprosthesis](./neuroscience/)** — gave conversational-speed communication back to people paralyzed by ALS and stroke.

## 🤝 Contributing

Know of a documented case that belongs here? **Contributions are very welcome.** See [CONTRIBUTING.md](./CONTRIBUTING.md) for the (short) guidelines. In brief:

- Add your entry to the relevant field's `README.md` using the existing format.
- **Every entry must cite a primary or highly credible source.**

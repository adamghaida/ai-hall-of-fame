# 🛠️ How to recreate: Matching — and beating — radiologists at breast-cancer screening

*This file is a practical starting point for reproducing or exploring the result — code, data, models, and (where one exists) the actual prompt or method. It is not official documentation; always defer to the primary sources.*

The exact model/data are not fully public (patient-privacy constraints), but the task is highly reproducible on open data: train a CNN classifier on public mammography datasets (e.g. **CBIS-DDSM**, or the **RSNA Screening Mammography** Kaggle challenge, which was built precisely to reproduce this kind of result) and evaluate against biopsy-confirmed labels and reader studies.

# 🛠️ How to recreate: Detecting diabetic retinopathy at specialist level

*This file is a practical starting point for reproducing or exploring the result — code, data, models, and (where one exists) the actual prompt or method. It is not official documentation; always defer to the primary sources.*

Reproducible on public data: the **EyePACS/Kaggle Diabetic Retinopathy** dataset and **Messidor-2** (used as a benchmark in the original paper) let you train and evaluate a fundus-image classifier. A standard ImageNet-pretrained CNN fine-tuned on graded images reproduces the core result; the hard part the authors solved was assembling large, consistently-graded labels.

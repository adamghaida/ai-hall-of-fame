# 🛠️ How to recreate: Dermatologist-level skin-cancer classification

*This file is a practical starting point for reproducing or exploring the result — code, data, models, and (where one exists) the actual prompt or method. It is not official documentation; always defer to the primary sources.*

Reproducible with public dermatology datasets such as **ISIC / HAM10000**. Fine-tune an ImageNet-pretrained CNN on labeled dermoscopic or clinical lesion images and evaluate against expert-labeled test sets and reader studies. The original used transfer learning from GoogLeNet Inception — a recipe that still works.

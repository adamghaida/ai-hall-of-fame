# 🛠️ How to recreate: Kepler-90i — a neural network finds a hidden eighth planet

*This file is a practical starting point for reproducing or exploring the result — code, data, models, and (where one exists) the actual prompt or method. It is not official documentation; always defer to the primary sources.*

Open-sourced: **github.com/google-research/exoplanet-ml**. The idea: train a CNN to classify Kepler light-curve 'transits' as real planets vs. false positives, then apply it to under-searched targets. NASA's Kepler/K2 light curves are public via the **MAST** archive, so the full pipeline — from light curves to a trained classifier — is reproducible on a laptop.

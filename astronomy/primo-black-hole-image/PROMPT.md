# 🛠️ How to recreate: PRIMO — a sharper image of the M87 black hole

*This file is a practical starting point for reproducing or exploring the result — code, data, models, and (where one exists) the actual prompt or method. It is not official documentation; always defer to the primary sources.*

PRIMO builds a dictionary of image components via **PCA** over large libraries of physically-simulated black-hole images, then finds the combination consistent with the sparse EHT visibility measurements. The EHT has released data and imaging tools (e.g. the **eht-imaging** library, github.com/achael/eht-imaging); PRIMO's method is described in the ApJ paper.

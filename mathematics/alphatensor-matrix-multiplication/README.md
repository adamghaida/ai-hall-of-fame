# AlphaTensor — beating a 50-year-old matrix-multiplication record

**Field:** 🧮 Mathematics  ·  **When:** October 2022 · Nature

> An AI beat a benchmark for multiplying matrices that had stood since 1969.

## What happened
By framing algorithm discovery as a single-player game ('TensorGame'), AlphaTensor found faster matrix-multiplication algorithms — including one for 4×4 matrices that **improved on Strassen's 1969 algorithm** for the first time, plus algorithms tuned to run 10–20% faster on specific hardware (Nvidia V100, TPU v2).

## Why it matters
Matrix multiplication underlies graphics, simulation, and machine learning itself. AlphaTensor showed AI could discover provably-correct, faster fundamental algorithms.

# 📚 Context: AlphaTensor — beating a 50-year-old matrix-multiplication record

The result is 'provably correct' because each decomposition can be checked exactly — no trust in the network required. AlphaTensor also reignited human research: shortly after, mathematicians used its ideas to find further improvements, a nice example of AI and humans leapfrogging each other.

## Why it's in the Hall of Fame
Matrix multiplication underlies graphics, simulation, and machine learning itself. AlphaTensor showed AI could discover provably-correct, faster fundamental algorithms.

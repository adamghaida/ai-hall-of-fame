# FunSearch — a genuinely new answer to a long-open math problem

**Field:** 🧮 Mathematics  ·  **When:** December 2023 · Nature

> Believed to be the first time an LLM produced a verifiable, new discovery on an established open problem.

## What happened
FunSearch pairs a large language model with an automated evaluator and evolutionary search. Applied to the **cap set problem** in extremal combinatorics, it discovered new, larger constructions than any previously known; it also found improved heuristics for online **bin packing**.

## Why it matters
Rather than retrieving a known result, FunSearch generated mathematical knowledge that did not previously exist — and because candidates are programs scored by an evaluator, the output is verifiable.

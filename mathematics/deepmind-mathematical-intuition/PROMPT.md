# 🛠️ How to recreate: Guiding human intuition — a new knot-theory theorem

*This file is a practical starting point for reproducing or exploring the result — code, data, models, and (where one exists) the actual prompt or method. It is not official documentation; always defer to the primary sources.*

The workflow is very reproducible with standard tools. (1) Generate a dataset of mathematical objects and their invariants (e.g. knots and their signatures / hyperbolic invariants). (2) Train a supervised model to predict one invariant from others. (3) Use **saliency / attribution** to see which inputs drive predictions, hypothesize a relationship, then test and prove it. DeepMind released guidance and code notebooks alongside the paper.

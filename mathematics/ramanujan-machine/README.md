# The Ramanujan Machine — a conjecture generator for fundamental constants

**Field:** 🧮 Mathematics  ·  **When:** February 2021 · Nature

> Algorithms that dream up new formulas for π, e, and the Riemann zeta function.

## What happened
Technion researchers built the **Ramanujan Machine**, which automatically generates conjectured formulas — especially continued-fraction representations — for fundamental constants like **π, e, Catalan's constant**, and values of the Riemann zeta function. Some conjectures it produced were previously unknown and were later proved.

## Why it matters
It flips the usual direction of discovery: instead of proving known formulas, the machine proposes new mathematical truths for humans to prove, echoing the intuition of Srinivasa Ramanujan.

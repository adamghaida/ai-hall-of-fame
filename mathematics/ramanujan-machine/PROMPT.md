# 🛠️ How to recreate: The Ramanujan Machine — a conjecture generator for fundamental constants

*This file is a practical starting point for reproducing or exploring the result — code, data, models, and (where one exists) the actual prompt or method. It is not official documentation; always defer to the primary sources.*

Fully open and even crowd-sourced: **github.com/RamanujanMachine** and **ramanujanmachine.com**. The algorithms (e.g. the 'Meet-In-The-Middle' and gradient-descent variants) numerically search enormous spaces of continued fractions for expressions that match a constant to high precision, then flag matches as conjectures. You can run the search on your own laptop and submit new conjectures.

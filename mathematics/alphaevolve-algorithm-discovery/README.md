# AlphaEvolve — breaking Strassen again, and improving ~50 open problems

**Field:** 🧮 Mathematics  ·  **When:** May 2025

> A general-purpose discovery engine that improves real algorithms and open math bounds.

## What happened
AlphaEvolve, a Gemini-powered evolutionary coding agent, found a way to multiply 4×4 **complex-valued** matrices in **48 scalar multiplications** (beating Strassen's 49 for this case for the first time since 1969). Across ~50 open math problems it matched or surpassed the state of the art — including improving a bound on the **kissing number in 11 dimensions** — and it recovered a slice of Google's data-center compute.

## Why it matters
Where AlphaTensor was specialized, AlphaEvolve is general: it evolves arbitrary code evaluated by any scorer, letting one system improve mathematics, hardware scheduling, and chip-design subroutines alike.

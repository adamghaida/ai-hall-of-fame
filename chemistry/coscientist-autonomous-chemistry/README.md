# Coscientist — a GPT-4 agent that designs and runs its own experiments

**Field:** 🧪 Chemistry  ·  **When:** December 2023 · Nature

> An LLM that planned real chemistry and executed it on lab robots from a plain-English prompt.

## What happened
**Coscientist**, built at Carnegie Mellon, couples GPT-4 with tools — web/documentation search, code execution, and a cloud robotic lab — to autonomously design, plan, and run experiments. From a one-line prompt it optimized **palladium-catalysed cross-coupling reactions** (Suzuki and Sonogashira) on real hardware.

## Why it matters
It closed the loop from natural-language goal → literature reasoning → experimental design → physical execution, a milestone toward self-driving laboratories.

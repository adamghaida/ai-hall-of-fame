# 🛠️ How to recreate: AlphaFold — solving protein folding (Nobel Prize in Chemistry 2024)

*This file is a practical starting point for reproducing or exploring the result — code, data, models, and (where one exists) the actual prompt or method. It is not official documentation; always defer to the primary sources.*

Open-sourced: **github.com/google-deepmind/alphafold** (AF2) and **alphafold3** (2024, under a research license). You rarely need to run it: look up any structure in the **AlphaFold Protein Structure Database** (alphafold.ebi.ac.uk). To run inference yourself you need the sequence, a multiple-sequence alignment (MSA) from genetic databases, and a GPU; **ColabFold** offers a free, lightweight route in a browser.

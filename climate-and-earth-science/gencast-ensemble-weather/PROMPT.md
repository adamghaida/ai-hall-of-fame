# 🛠️ How to recreate: GenCast — state-of-the-art ensemble weather forecasting

*This file is a practical starting point for reproducing or exploring the result — code, data, models, and (where one exists) the actual prompt or method. It is not official documentation; always defer to the primary sources.*

Open-sourced alongside GraphCast: **github.com/google-deepmind/graphcast** (GenCast weights and code included). It applies a conditional diffusion process to generate many plausible future atmospheric states from the same initial condition, forming the ensemble. Trained on **ERA5**; inference produces a full ensemble in minutes.

# AlphaChip — AI that lays out the chips it runs on

**Field:** 💻 Computer Science  ·  **When:** 2021 · Nature

> Reinforcement learning designs chip floorplans used in Google's own TPUs.

## What happened
**AlphaChip** treats **chip floorplanning** (placing macro blocks on silicon) as a game, using a graph neural network to place components and earn reward for layout quality. It produces superhuman-or-comparable layouts in hours instead of weeks, and has been used across multiple generations of Google **TPU** chips.

## Why it matters
Physical design is a critical, labor-intensive bottleneck in making faster chips — the hardware that in turn trains bigger AI. AlphaChip closed part of that loop.

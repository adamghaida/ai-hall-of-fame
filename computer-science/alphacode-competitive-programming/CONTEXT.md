# 📚 Context: AlphaCode — competitive programming at the median human level

AlphaCode's insight was scale plus filtering: most sampled programs are wrong, but if you can cheaply test them against provided examples, you only need a few correct ones to survive. It foreshadowed the reasoning-model era; by 2024–2025, systems like AlphaCode 2 and general LLMs reached gold-medal levels at the International Olympiad in Informatics.

## Why it's in the Hall of Fame
Competitive programming demands reading a natural-language puzzle and inventing a correct, efficient algorithm — a reasoning task, not a lookup. Reaching median-human performance was a landmark for code generation.

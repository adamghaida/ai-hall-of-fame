# 📚 Context: AlphaDev — faster sorting, now shipping in the C++ standard library

What makes this concrete rather than academic is real-world adoption: the routines live in the standard library every C++ program links against. AlphaDev worked at the assembly level because that's where micro-optimizations (fewer instructions, better pipelining) live — a search space too tedious and unintuitive for humans to fully explore.

## Why it's in the Hall of Fame
It was the first change to those C++ sorting algorithms in over a decade — and the first authored by an AI. Sorting runs everywhere, so the speedup compounds across essentially all computing.

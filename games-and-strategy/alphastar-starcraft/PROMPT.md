# 🛠️ How to recreate: AlphaStar — Grandmaster at StarCraft II

*This file is a practical starting point for reproducing or exploring the result — code, data, models, and (where one exists) the actual prompt or method. It is not official documentation; always defer to the primary sources.*

DeepMind released pseudocode and an implementation scaffold: **github.com/google-deepmind/alphastar**, and Blizzard/DeepMind provide the **PySC2** learning environment (github.com/google-deepmind/pysc2) plus large replay datasets. Full training used significant compute, but PySC2 lets you experiment with the same interface the agents used.

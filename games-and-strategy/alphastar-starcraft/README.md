# AlphaStar — Grandmaster at StarCraft II

**Field:** ♟️ Games & Strategy  ·  **When:** 2019 · Nature

> Superhuman play in a real-time game of hidden information and vast action spaces.

## What happened
DeepMind's **AlphaStar** reached **Grandmaster** rank in **StarCraft II**, above **99.8%** of ranked human players, across all three races — using multi-agent reinforcement learning and a 'league' of continually adapting strategies.

## Why it matters
StarCraft combines real-time control, imperfect information, long horizons, and an enormous action space — a very different, messier challenge than turn-based board games.

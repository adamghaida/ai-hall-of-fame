# 🛠️ How to recreate: CICERO — human-level play in Diplomacy, negotiation included

*This file is a practical starting point for reproducing or exploring the result — code, data, models, and (where one exists) the actual prompt or method. It is not official documentation; always defer to the primary sources.*

Open-sourced: **github.com/facebookresearch/diplomacy_cicero** (code and model weights), built on the open **diplomacy** game engine. The system pairs a dialogue model (fine-tuned to produce messages consistent with an intended action plan) with a strategic reasoning module that predicts others' moves — you can run agents against each other or in the online environment described.

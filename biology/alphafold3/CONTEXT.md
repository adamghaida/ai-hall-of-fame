# 📚 Context: AlphaFold3 — the structure of life's molecules, together

AF3 swapped AF2's equivariant structure module for a diffusion model that generates atomic coordinates directly, letting one network handle many molecule types. Caveats: it was initially available only through a usage-limited web server with no code (which drew significant criticism from the research community before code was later released for academic use), and it can still hallucinate plausible-looking structure in disordered regions. It builds directly on the AlphaFold entry in Chemistry.

## Why it's in the Hall of Fame
Biology happens through interactions, not single static proteins. Accurately predicting protein-ligand and protein-DNA/RNA complexes is central to drug discovery, which is Isomorphic Labs' entire premise.

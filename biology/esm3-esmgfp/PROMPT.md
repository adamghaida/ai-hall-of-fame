# 🛠️ How to recreate: ESM3 — a glowing protein equivalent to 500 million years of evolution

*This file is a practical starting point for reproducing or exploring the result — code, data, models, and (where one exists) the actual prompt or method. It is not official documentation; always defer to the primary sources.*

Open weights (open models) are released: **github.com/evolutionaryscale/esm**. ESM3 is 'promptable' across three tracks — sequence, structure, and function — so you can, for example, fix a few catalytic residues and let the model fill in the rest. Generate candidates, filter computationally, then synthesize and assay the best (esmGFP was found by chaining prompts and selecting bright variants).

# A robot that plays amateur-level competitive table tennis

**Field:** 🤖 Robotics  ·  **When:** August 2024

> The first learned robot to hold full rallies and win matches against people.

## What happened
DeepMind built the first learned robot agent to reach **amateur human level** in **competitive table tennis**, playing full matches against people. It won **13 of 29** games — beating all beginners and holding a winning record against intermediates (though losing to advanced players).

## Why it matters
Table tennis compresses perception, prediction, and high-speed precise control into fractions of a second against an adaptive opponent — a demanding testbed for real-world, real-time robot learning.

# 🛠️ How to recreate: FlyWire — the first complete wiring map of an adult brain

*This file is a practical starting point for reproducing or exploring the result — code, data, models, and (where one exists) the actual prompt or method. It is not official documentation; always defer to the primary sources.*

Fully public: explore the connectome at **flywire.ai** and **codex.flywire.ai**, download the graph, and even run circuit simulations (Berkeley researchers simulated the whole fly brain on a laptop). The segmentation used flood-filling networks on EM volumes; the data and analysis notebooks are open for reuse.

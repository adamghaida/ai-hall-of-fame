# 🛠️ How to recreate: Handwriting BCI — thinking letters onto a screen

*This file is a practical starting point for reproducing or exploring the result — code, data, models, and (where one exists) the actual prompt or method. It is not official documentation; always defer to the primary sources.*

Open data and code: **github.com/fwillett/handwritingBCI** with neural datasets on Dryad. You can retrain the RNN decoder on the released recordings and reproduce the character-recognition results without any hardware — a rare, fully-open BCI dataset.

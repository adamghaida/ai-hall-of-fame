# 🛠️ How to recreate: A-Lab — a robotic lab that makes new materials on its own

*This file is a practical starting point for reproducing or exploring the result — code, data, models, and (where one exists) the actual prompt or method. It is not official documentation; always defer to the primary sources.*

Building a full A-Lab needs robotics (furnaces, powder handling, XRD), but the software stack — target selection, recipe proposal via ML, and automated XRD phase analysis — is described in the paper and partly open through the Ceder group. A minimal version pairs a synthesis-recipe recommender with an automated characterization/decision loop.

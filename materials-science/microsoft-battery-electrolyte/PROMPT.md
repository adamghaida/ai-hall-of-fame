# 🛠️ How to recreate: An AI-screened battery electrolyte using ~70% less lithium

*This file is a practical starting point for reproducing or exploring the result — code, data, models, and (where one exists) the actual prompt or method. It is not official documentation; always defer to the primary sources.*

The workflow is a cascade of increasingly expensive filters over a large materials database (composition screens → ML stability/conductivity predictors → physics-based simulation → lab synthesis). You can reproduce the concept with the open **Materials Project** + ML property predictors; Microsoft's specific 'Azure Quantum Elements' stack is a hosted product.
